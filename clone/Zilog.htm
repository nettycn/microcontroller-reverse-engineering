About Zilog

Zilog is a legendary semiconductor company famous for the Z80 8‑bit CPU, which powered many home computers and embedded systems. Today, Zilog produces modern derivatives like the eZ80 and Z8051 families. Their microcontrollers are still widely used in industrial controls, consumer electronics, and retro computing. Zilog’s eZ80 is a fully compatible, pipelined version of the classic Z80. They also offer Z80‑based MCUs with integrated peripherals like UART, SPI, and I2C. Zilog’s Z8051 family is an 8051‑compatible core with enhanced features. Their products are known for low power consumption and small footprint. Zilog provides development tools including assemblers, compilers, and simulators. They also offer in‑circuit programmers and debuggers. Zilog’s chips are often found in legacy equipment that is still in operation. The company has a strong community of enthusiasts and engineers. Zilog supports both assembly and C programming languages. They offer application notes for common use cases. Zilog’s microcontrollers have been used in vending machines, medical devices, and automotive modules. The company was acquired by IXYS and later by Littelfuse, but the Zilog brand persists. Zilog continues to release new variants with additional memory and peripherals. Their Z80 architecture is one of the most influential designs in computing history. Zilog also offers secure MCUs with encryption capabilities. They have a wide temperature range for industrial applications. Zilog’s products are cost‑effective and easy to use. They provide long‑term availability for legacy designs. Zilog’s support includes online forums and technical documents. Their microcontrollers are also used in hobbyist projects and retro gaming. Zilog’s commitment to backwards compatibility ensures code portability. They have a reputation for reliable and robust designs. Zilog also produces serial communication controllers and other peripheral chips. Their products remain relevant in many niche applications.

Zilog Security Features

Zilog implements modest security features suitable for many embedded applications. Their eZ80 devices include lock bits that can prevent readback of the internal flash. Once locked, the program memory cannot be read via the debug interface. However, these lock bits can be bypassed through glitch attacks. Some Zilog MCUs have a hardware encryption engine to decrypt code stored in external memory. This adds a layer of protection, but the key must be kept safe. Zilog also provides a unique device serial number for authentication, which can prevent cloning. However, without proper validation, it may not be effective. Older Z80 parts have no security features at all, making them trivial to read. For those, we can simply use a logic analyzer to capture the bus cycles. For modern eZ80, we have developed methods to extract the firmware by exploiting the bootloader. The bootloader can sometimes be tricked into dumping memory. Side‑channel power analysis can reveal keys during encryption. We have successfully hacked Zilog devices using electromagnetic probing. Another approach involves using ultraviolet light to erase the lock fuses on OTP parts. Once the lock is removed, we can read the entire memory. For secure applications, Zilog recommends using external security ICs. Despite these limitations, many legacy systems rely on Zilog MCUs. We can duplicate the firmware onto a replacement chip. Our team can recover firmware from corrupted devices as well. We use invasive techniques like decapsulation to read the silicon directly. This allows us to recover code even from locked parts. Zilog’s security is not as advanced as modern ARM chips, but it is sufficient for many industrial uses. For clients needing to migrate away from Zilog, we can extract the code and port it. We also provide disassembly and analysis of the extracted binary. Our services include both non‑invasive and invasive methods. We have a high success rate in recovering Zilog firmware.
