Feeling Technology Reverse Engineering

Specialised services for Feeling 8-bit MCUs and touch controllers

Brand Overview

Feeling Technology is a Taiwanese fabless company known for its low‑cost 8‑bit microcontrollers, widely used in consumer electronics, toys, small home appliances, remote controls, timers, and LED drivers. They also produce capacitive touch sensors and human interface devices. Their microcontrollers are based on an 8051‑compatible core or a proprietary RISC architecture, offering both OTP and flash variants, some with embedded EEPROM.

Feeling devices are cost‑effective for high‑volume productions, but security is often minimal, with only basic lock bits, making them relatively easy to reverse engineer. We have extracted firmware from many Feeling MCUs using simple glitching methods. Many legacy products still use Feeling chips, so reverse engineering is vital for repairs and clone production. Our team is familiar with the programming protocols and memory maps, and we can unlock the chip and read the full code without damaging it.

For touch sensors, we can recover calibration data and sensitivity parameters to reproduce the exact touch behavior in a clone. We also offer custom IC design services for existing products. Our services include complete firmware extraction, disassembly, analysis, and identification of hidden features or backdoors. With our help, you can continue production of obsolete Feeling‑based devices at a cost‑effective price.

Security Features & Reverse Engineering Insights

Feeling Technology implements a basic security scheme through a code protection fuse; when blown, the programming interface is disabled, preventing readback. However, this protection is easily defeated by voltage glitching during power‑up – we can hack the device by ramping the supply voltage faster than the internal reset, causing the chip to enter an unprotected state, allowing us to dump the memory. For OTP variants, the protection is permanent, but we can use micro‑probing to extract data by decapsulating the chip and visually reading the charge of each memory cell, achieving 100% accuracy.

Some Feeling MCUs include a unique device ID that can be used for authentication; we can clone this ID by reading it and programming it into another device, allowing us to duplicate the entire chip behavior. Our side‑channel analysis can also extract secrets if encryption is used. Feeling’s touch controllers have configuration registers that are often unprotected; we can read and modify these registers to alter touch sensitivity, useful for creating clones with different performance.

We have also discovered that many Feeling devices have unused memory areas containing hidden data or calibration values. We always perform a full memory scan to recover all available information. Our tools include custom scripts for automated extraction, reducing turnaround time significantly. We provide a complete analysis of the firmware, including function identification and reconstruction of the original C code from assembly. Our service is invaluable for companies that have lost source code, and we have helped many clients bring old products back to life. With a nearly 100% success rate and competitive pricing, MikaTech is your go‑to for Feeling reverse engineering.
