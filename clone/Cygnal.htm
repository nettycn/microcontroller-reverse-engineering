About Cygnal (Silicon Labs)

Cygnal Integrated Products, later acquired by Silicon Labs, was a pioneer in high-speed 8-bit microcontrollers based on the 8051 architecture. The company introduced the C8051F series, which broke the traditional 12-clocks-per-instruction barrier, achieving performance comparable to 16-bit MCUs. These devices integrated high-resolution ADCs, DACs, voltage references, and PWM modules, making them ideal for precision analog applications. In 2014, Silicon Labs continued the legacy with the EFM8 family, offering low-power, 8051-based MCUs for consumer and industrial use. Simultaneously, they launched the EFM32 32-bit ARM Cortex-M series, known for their ultra-low power consumption (down to 0.9 µA in sleep). Cygnal's original C8051F devices were widely used in sensor interfaces, motor control, and medical devices. The company was known for its innovative on-chip debugging and programming interfaces, which included a two-wire C2 protocol. This interface allowed for in-system programming and debugging, but also introduced vulnerabilities that we can exploit. Today, Silicon Labs offers a broad portfolio of microcontrollers, wireless SoCs, and clock generators. Their MCUs are found in IoT devices, smart meters, and home automation. Despite their advanced features, many legacy Cygnal devices are still in use, and their firmware often contains valuable intellectual property. Our reverse engineering services cover both the legacy C8051F series and the modern EFM8/EFM32 families. We have extensive experience in extracting firmware from these devices, even when the security lock bits are set. The C2 interface can be used for debugging, but if locked, we resort to other methods. We have successfully bypassed the read-out protection on many Cygnal devices using fault injection and power analysis. For the EFM32 ARM chips, we leverage the standard JTAG/SWD interfaces, but when secured, we apply similar attack techniques. Our team has developed custom tools to communicate with the C2 port, allowing us to attempt brute-force attacks on the lock mechanism. Some devices also have a "bootloader" that can be used for firmware updates, but this can be exploited to extract the main firmware. Security Features and Attack Methods

Cygnal (Silicon Labs) devices incorporate various security features to protect the firmware and configuration data. The most common is the use of flash security lock bits that prevent reading and writing to the flash memory through the debug interface (C2 or JTAG). Once these bits are set, the device cannot be read unless the lock is cleared, which typically requires a mass erase. However, mass erase also erases the user data, making it unusable. To prevent unauthorized access, the lock bits are usually stored in a separate area of flash that is automatically locked. Some devices also support a "secure boot" option where the bootloader verifies the signature of the application before executing it. Additionally, the EFM32 series includes a unique device ID that can be used for authentication and anti-cloning. Some devices have a tamper detection circuit that erases the keys upon detecting a physical intrusion. Despite these measures, we have developed effective attack strategies. For C2 interface, we can use voltage glitching to corrupt the lock check logic, allowing us to bypass the protection and read the flash. By carefully adjusting the clock or supply voltage, we can make the CPU skip the lock verification. We have successfully performed this on multiple C8051F devices. For EFM32 with SWD, we have used a combination of fault injection and side-channel analysis to extract the encryption keys stored in the secure area. We also use decapsulation to expose the die and then probe the flash memory directly. This approach is invasive but yields the full binary. For EFM8 devices, we have discovered that the bootloader can sometimes be tricked into entering a firmware update mode that allows reading the main flash. By sending specific commands, we can cause the bootloader to dump the contents. We have also found that some devices have a "backdoor" in the manufacturing test mode that can be activated via JTAG, granting full access. Our team maintains a database of known vulnerabilities for various Cygnal parts. We also perform power analysis to extract cryptographic keys during encryption/decryption operations. For example, we have recovered AES keys from EFM32 devices by measuring the power consumption during AES processing. This is a non-invasive method that leaves the device intact. In cases where the device is locked and no other method works, we resort to FIB (focused ion beam) to cut specific traces and gain control over the security logic. We have successfully used this technique to unlock several EFM32 microcontrollers.
