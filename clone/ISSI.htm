About ISSI

ISSI (Integrated Silicon Solution Inc.) is a renowned manufacturer of high‑performance memory and microcontroller products. They combine flash, SRAM, and DRAM with CPU cores to create SoC solutions. ISSI’s microcontrollers are widely used in automotive, industrial, and communications. Their product portfolio includes 8‑bit, 16‑bit, and 32‑bit architectures. ISSI is known for its high‑density flash and low‑leakage SRAM. They offer a variety of package options including BGA and QFN. ISSI’s MCUs often integrate analog peripherals like ADCs, DACs, and op‑amps. They are used in battery management systems and power inverters. ISSI also produces radiation‑tolerant chips for space applications. The company has a strong focus on automotive grade (AEC‑Q100) devices. Their microcontrollers support CAN, LIN, and FlexRay interfaces. ISSI provides comprehensive development tools and software libraries. They are a key supplier for many Tier‑1 automotive OEMs. ISSI’s memory technologies are known for high endurance and retention. They offer both serial and parallel flash interfaces. ISSI also creates custom ASICs for specific client needs. Their R&D investments include advanced packaging and 3D integration. ISSI’s products are designed for harsh environments with wide temperature ranges. They have a reputation for reliable quality and long product lifecycles. ISSI collaborates with leading foundries for manufacturing. Their security solutions include encryption and authentication. ISSI is actively developing secure elements for IoT. They are expanding into AI and machine learning acceleration. ISSI’s focus on memory integration sets them apart from general‑purpose MCU vendors. They are a trusted partner for mission‑critical systems. ISSI’s global presence ensures supply chain stability. They continue to innovate in both memory and logic domains.

ISSI Security Features

ISSI incorporates multiple security mechanisms to protect IP and data. Their MCUs feature hardware encryption engines for AES, DES, and RSA. This allows firmware to be stored encrypted, requiring a key to decrypt during boot. The keys are kept in a secure region that cannot be read via standard interfaces. ISSI also provides unique device IDs for authentication purposes. They implement secure boot with signature verification to ensure only trusted code runs. Memory protection units (MPUs) isolate critical code and data sections. Debug ports can be permanently locked via OTP fuses, preventing external readback. However, fault injection attacks can sometimes unlock these ports. ISSI includes tamper detection pins that trigger data erasure on intrusion. Their devices have a secure key storage with zeroization capability. To extract firmware, one might need to clone the entire chip or bypass protection. Side‑channel analysis (power and electromagnetic) can reveal keys during cryptographic operations. Our team has successfully recovered keys from ISSI devices using differential power analysis. We have also used laser fault injection to alter program flow and dump memory. ISSI’s security is robust, but no system is invulnerable. We have developed methods to attack the bootloader and extract the firmware. For automotive variants, we can read the configuration and calibration data. ISSI’s memory‑integrated designs make them attractive for reverse engineering. We can recover firmware and clone it onto equivalent devices. Our services include non‑invasive and invasive techniques depending on the protection level. We can also provide a full disassembly and analysis of the code. ISSI’s ongoing security updates mean we must stay current with new countermeasures. MikaTech invests in R&D to overcome the latest protections.
