About Atmel

Atmel Corporation was a pioneering semiconductor company, now part of Microchip Technology following the 2016 acquisition. Atmel is famous for its AVR 8‑bit and 32‑bit microcontrollers, widely used in Arduino boards and countless embedded projects. Their AT91SAM series are ARM‑based 32‑bit MCUs for more demanding applications. Atmel also produced 8051‑compatible AT89 series devices. The company’s products are known for low power consumption, ease of use, and extensive peripheral sets. Atmel’s AVR architecture features a modified Harvard architecture with a rich instruction set. They offer a wide range of memory sizes, from tiny 1KB to 256KB flash. Atmel’s microcontrollers are used in automotive, industrial, consumer, and IoT applications. They also produce secure elements like the ATECC series for cryptographic authentication. Atmel provided development tools including Atmel Studio, now integrated into Microchip’s MPLAB X. Their devices support interfaces like UART, SPI, I2C, USB, CAN, and Ethernet. Atmel’s picoPower technology enables ultra‑low power operation. They also offer touch and gesture sensing solutions. Atmel’s QTouch library is popular for capacitive buttons. The company has a strong community of hobbyists and professionals. Atmel’s documentation is comprehensive and well‑regarded. Their devices are often used in medical devices and wearable technology. Atmel also produced FPGA products under the AT40K family. Their secure MCUs include hardware crypto engines. Atmel’s acquisition by Microchip expanded their combined portfolio significantly. The AVR architecture is still actively developed and supported. Atmel’s legacy products remain in production for many customers. They have a reputation for robust and reliable operation. Atmel also offers radiation‑hardened versions for aerospace. Their products are available in many package types. Atmel’s contribution to the maker movement is immense. The company continues to innovate under Microchip’s umbrella.

Atmel Security Features

Atmel incorporates a range of security features across its product families to protect firmware and sensitive data. AVR devices include lock bits that can prevent readback of the program memory. When these bits are set, the flash and EEPROM contents cannot be read via the debug interface. However, numerous attack vectors have been discovered to bypass these locks. For older devices like the ATmega328, the lock bits can be reset using high‑voltage programming, effectively unlocking the chip. More advanced microcontrollers, such as the AT91SAM series, implement secure boot with cryptographic signature verification. This ensures that only authenticated firmware can execute. Some SAM devices feature a TrustZone® environment for secure processing. Atmel also provides hardware crypto engines for AES, DES, and SHA, allowing firmware to be stored encrypted. The decryption keys are stored in a secure memory region that is inaccessible via standard read operations. Despite these measures, researchers have demonstrated successful attacks using side‑channel power analysis to recover encryption keys. Glitch attacks can also disrupt the secure boot process, enabling an attacker to extract the bootloader. We have successfully dumped firmware from ATmega328P chips using a glitch on the reset line. For AT91SAM devices, we have employed electromagnetic analysis to read the internal flash. Another method involves using a logic analyzer to capture data on the external bus during a memory read. Once the data is captured, we can reconstruct the firmware. Atmel’s OTP (One‑Time Programmable) parts can be read by decapsulating the chip and using a microscope to directly view the bit cells. This allows us to duplicate the entire code onto a new device. The ATECC secure elements are more robust, but even they have been hacked using differential power analysis. Our team has developed custom tools to attack Atmel’s security mechanisms. We can recover the firmware even when the lock bits are enabled. For legacy AT89 parts, the lock bits are often weak and can be bypassed with simple glitches. We have also used fault injection to alter program execution and dump the memory. Atmel’s security is sufficient for many applications but not for military‑grade. We offer comprehensive extraction and recovery services for all Atmel MCUs.
