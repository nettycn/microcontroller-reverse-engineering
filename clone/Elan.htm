Elan Microelectronics Reverse Engineering

Specialised services for Elan 8-bit and 32-bit microcontrollers and touch controllers

Brand Overview

Elan Microelectronics is a Taiwanese fabless semiconductor company established in 1994, well‑known for their low‑cost 8‑bit microcontrollers often used in consumer electronics. Their EM78 series is compatible with Microchip’s PIC architecture but with variations, and they also produce ARM‑based 32‑bit MCUs and capacitive touch controllers. Elan chips are found in remote controls, small appliances, toys, computer peripherals, and smart home devices, and they have a strong presence in the Chinese and Southeast Asian markets.

Many Elan devices feature embedded EEPROM and flash memory with security bits, but the implementation is often basic, relying on simple lock bits, which makes them relatively easier to reverse engineer compared to high‑end counterparts. Nevertheless, we have encountered devices with proprietary encryption algorithms. Elan also offers OTP (one‑time‑programmable) versions for mass production, which require special techniques for reading since they cannot be reprogrammed. Our team has developed methods to extract code from Elan OTP chips using micro‑probing, and we have successfully cloned Elan microcontrollers for various industrial clients.

We are familiar with Elan’s proprietary programming interface and debug protocols, and we can bypass the security locks to read out the complete firmware. Our services cover both flash‑based and OTP‑based Elan devices, including firmware extraction, disassembly, functional analysis, and replacement solutions for obsolete chips. With over 100 successful Elan projects, we have the expertise to help you regain control of your Elan‑powered products.

Security Features & Reverse Engineering Insights

Elan microcontrollers typically implement a simple security scheme based on configuration bits. The code protection lock prevents reading the program memory via the programming interface, but this lock can often be defeated by exploiting the power‑up timing. We can hack the device by glitching the power supply during the read sequence, which forces the chip to skip the security check and allows us to dump the entire memory. For OTP variants, the lock is permanent, but we can use invasive techniques to extract bits by decapsulating the die and using a scanning electron microscope to read the charge state of each memory cell. We have successfully recovered the complete code from Elan OTP chips this way.

For flash‑based devices, we can often use a debug interface (ICSP) to read back the contents; even when the interface is disabled, we can re‑enable it by manipulating the reset vector. We have developed a custom bootloader that exploits a buffer overflow to unlock the flash, allowing us to extract the firmware without altering the original chip. Elan’s 32‑bit ARM devices have more robust security, including read‑out protection (RDP), but we have found that RDP can be downgraded via a glitch attack on the option bytes, after which we can read the flash using standard SWD. We can also recover encryption keys stored in the unique ID area, which are often used for firmware authentication, and clone them with precision.

Our side‑channel analysis on Elan ARM MCUs has revealed leakage in the AES routine, allowing us to extract secret keys even when RDP is at the highest level. For touch controllers, security is minimal, and we can often read the configuration directly. We have cloned Elan touch firmware to replicate functions in counterfeit products, and our approach includes both non‑invasive and invasive methods depending on the client’s needs. We can recover the algorithm used for touch sensing to create compatible replacements. Overall, Elan’s security is generally weak compared to competitors, but we still apply rigorous techniques to ensure 100% success.

We have extracted firmware from Elan chips that were thought to be unbreakable, and our tools allow us to duplicate the entire chip behaviour, including timing and peripherals, to produce a functional clone that works seamlessly in the target system. We also offer decryption services for any encrypted data stored in Elan MCUs by reverse‑engineering the encryption scheme. Our team constantly researches new attacks and stays ahead of updates, providing detailed documentation of the extraction process for your records.
